Accès privé  ·  optionnel

Outil à usage personnel. Si vous avez protégé votre serveur avec un code (variable ACCESS_CODE), saisissez-le ici : il est mémorisé uniquement dans ce navigateur. En usage local, laissez vide.

Mode direct (sans serveur)  ·  optionnel

Par défaut, l'atelier passe par le serveur du site : la clé API reste côté serveur et n'est jamais exposée. Vous n'avez rien à renseigner ici.

Si vous ouvrez ce fichier seul, sans serveur (double-clic), collez une clé API Claude (Opus 4.8) ci-dessous pour activer le mode direct : elle est alors enregistrée uniquement dans ce navigateur (localStorage) et envoyée directement à l'API d'Anthropic. Obtenir une clé : console.anthropic.com.

Mode serveur — aucune clé nécessaire.
